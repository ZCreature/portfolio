Tile plates

Two home page tiles animate their photographs by pixel position, so each depends on one exact image. This page rebuilds or checks what they measure. Serve the repo root locally (python3 -m http.server) and open /scripts/tile-plates/. Every value is read from the tile scripts themselves, so there is nothing to keep in step here.
